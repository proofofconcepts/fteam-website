---
name: frontend-review
description: Review frontend code for best practices, performance, and maintainability.
---

When reviewing frontend code, consider the following aspects:
1. **Code Quality**: Check for clean, readable, and maintainable code. Look for consistent coding styles, meaningful variable names, and proper use of comments.
2. **Performance**: Evaluate the code for performance optimizations, such as minimizing DOM manipulations, using efficient algorithms, and optimizing asset loading.
3. **Best Practices**: Ensure that the code follows best practices for frontend development, including responsive design, accessibility, and security.
4. **Testing**: Verify that the code includes appropriate tests, such as unit tests, integration tests, and end-to-end tests, to ensure reliability and catch potential issues early.
5. **Documentation**: Check for clear and comprehensive documentation that explains the code's functionality, usage, and any dependencies or configurations required.
